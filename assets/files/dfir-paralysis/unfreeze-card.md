# The Unfreeze Card

Print it. Tape it next to your screen. Use it the moment you notice you're stuck.

## 1. Name the freeze (30 seconds)
- [ ] **Volume**: too much data, no starting point
- [ ] **Pressure**: someone is waiting, judging, or asking hard questions
- [ ] **Rabbit hole**: deep in one artifact, lost the case

## 2. Write the question (2 minutes)
> "Did ____ happen, on ____, by ____?"

One sentence. If you can't write it, your first job is to ask the requester, not to open a tool.

## 3. What would prove it / disprove it? (2 minutes)
| If true, I'd expect… | If false, I'd expect… |
|---|---|
|  |  |

## 4. Smallest dataset that answers it (1 minute)
Which 3 artifacts, which host, which time window? Everything else waits.

## 5. Timebox (set an actual timer)
- 45 minutes on this question, then step back and re-read this card.

## 6. Keep three lists while you work
- **Known** (with source)
- **Assumed** (needs proof)
- **Unknown** (and whether it matters)

## 7. Say it as an outcome
> "We found ____, which shows ____. It does / doesn't mean ____. Confidence: ____."
